Scribe's first native macOS foundation release, for Apple Silicon and macOS 14+.

Includes a structured document model, named paragraph styles, linked TextKit pages, A4/Letter/Legal page settings, outline navigation, native rich text editing, find/replace, statistics, focus mode, document tabs, recovery snapshots, native saves, basic DOCX/RTF/Markdown/text interchange, PDF export, and printing.

This is an early development release, not yet a replacement for Word or Pages. Tables, images, shapes, wrapping, review UI, track changes, footnotes, equations, and advanced DOCX fidelity are not implemented. Known import losses are reported. See the repository's feature matrix and validation notes.

The DMG is ad-hoc signed and not notarized. See the included installation instructions. A Developer ID identity is required for notarized distribution.
